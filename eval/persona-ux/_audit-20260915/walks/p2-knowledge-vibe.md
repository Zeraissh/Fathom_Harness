## 聊天优先的知识工作者

### 好

| 证据 | 原文 |
|---|---|
| 默认就是 Work 脸，占位是人话 | 普查：`faceOffice=true`，占位「说要做什么…」，发送键「发送」。欢迎：「说要做什么，回车就发。稿件、纪要、问答都可以从这里开始。」 |
| 新手卡第 1 页不再考写入圈 | 「打一句话，回车 / 在输入框里写下要做的事，按 Enter 发送。」 |
| 空态有成品例子 | 「做纪要 / 把材料收成可转发的短纪要」「做一页 / 一页介绍，浏览器里预览」「带出处问答」 |
| 点「做一页」只填输入框，不立刻开跑 | `B9-after-click` 输入变成：「做一页介绍：主题自拟，相对 CSS，不要外链。写完告诉我打开哪里预览。」 |
| Work 普通人话不再 HTTP 409 | `POST /api/runs` `workspace=office` 无 mode → **200** `764ad723-…`（随后评测停掉）。 |

### 不习惯

| 仍要先看见工作目录芯片（`D:\Work\scratc…0260915\web-a`）和右侧「先选一个工作目录。」 | 打开就能拖附件，不必懂圈禁。 |

### 不实用

| 证据 | 为什么 |

| Work 脸真发送：落盘 `mode=single`，但 `facade=design`、`workspace=office`（B1/B2/B4 的 `meta.json`）。写 `hello-b1.txt` 这种小事被标成设计脸 | 普通人话应是聊天；`/api/runs` 把 facade 报成 `mode` 也容易看错。 |
| 产物画布能打开 txt，但「做一页」本轮只填了词，没有跟写预览（未把 starter 发出去，避免占满 live 槽） | 交一份纪要要看见可下载文件。 |

收口：挡住第一次成功的 409 / 「运行任务」这两块，活页已经改过。还挡手的是 Work 脸被标成 `facade=design`，以及 web-a 上文件树空态盖住「其实已经选了目录」。

## Vibe / 设计师

### 好

| 证据 | 原文 |
|---|---|
| Work 脸空态就是稿件卡，不是仓库例子 | 「做一页 / 一页介绍，浏览器里预览」 |
| 预览坞存在：B1 打开 `hello-b1.txt` 看见 `ping`；关坞对话还在（hash 仍 `#/run/…`） | 画布是附注旁边的真预览，不是整页 `file://`。 |
| 不勾计划/核查也能发 | 默认 `plan=false` `verify=false`。 |

### 不习惯

| 证据 | 我本来以为会…… |
|---|---|
| 打开没有空白画布，右侧是「先选一个工作目录。」 | 一句话出预览，画布是真相。 |
| 点 starter 只填提示词，预览不会先出现骨架页 | 打「做一个……的页面」，视线立刻有画布。 |
| 本轮 scratch 里没有 WebGL 页。C 波对 `preview-seed.html` / 产物页找「点评」——没有三维零件可点 | 能指着预览说「这个按钮再大一点」。 |

### 不实用

| 证据 | 为什么 |
|---|---|
| 文件树点 seed 在普查里失败（`file-tree-open-seed`：`seed row not found`），同时坞外已经列着 `hello-seed.txt` / `preview-seed.html` | 树说谎时，设计师找不到那一页。 |
| 运行设置仍摊「领域包 / stm32-debug / kicad / 多 agent」——默认藏在「运行设置」里，这点比档案好；点开仍是工程台 | 工程配置应全部藏起来。 |

收口：Work 默认脸和「做一页」芯片对上了设计师的伸手；画布没有先于聊天出现，三维点评本轮无活页可射。
