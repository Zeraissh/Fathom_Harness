# P3 · 只审批的委托方 + 安全敏感用户

- **日期：** 2026-09-15
- **表面：** 仅 Web 只读 + 审批。未交新高权任务。观察已有 run + 指挥中心。
- **习惯伸手：** 委托方：待决定、计划、费用、停止。安全：默认是不是全放行、批准文案、拒绝后文件在不在、密钥有没有上屏。

---

## 只审批的委托方

### 好

| 证据 | 原文 |
|---|---|
| 底栏有指挥中心，路由标题「FATHOM · 指挥中心」 | 普查 `footer-board` / `route-#/board`。 |
| 花费在首页就能看见 | 顶栏「今日 $1.98」→ 点进设置；ARIA「花费：今日 $1.98 · 今日已用 20 次」。用量页标题「FATHOM · 消耗」。 |
| 批准卡人话，两个大按钮 | 「要新建或改 hello-code.txt，写入「code-ok」」/「允许」「拒绝」。 |
| 停止人脸话，不是「运行已完成」 | B4：「已停止：先列出当前目录的文件名…」「已停止 · 这次运行由你主动停止；已完成的工具调用与写入不会回滚。」 |
| 提问卡钉在输入上方 | 「◆ 有 3 个问题需要你定」+ 推荐选项 +「提交答复 / 都让它自己定」。 |

### 不习惯

| 证据 | 我本来以为会…… |
|---|---|
| 第一眼仍是对话列表，不是待审批看板。要自己点底栏「指挥中心」 | 打开就是「要你签字的事」。 |
| 提问卡在对话页看得见（「◆ 有 3 个问题需要你定」）。指挥中心在提问挂起时说了什么，本轮**没有**看板原文；普查截图是尚无 run 时的「没有运行中的任务」 | 待决定应能在看板看见。本卡不引用档案里的「没有等你决定的事」。 |
| 钱是全局台账（`/api/usage` 今日 $1.98，含评测机以外的 run），不是「这次 scratch 花了多少」 | 一屏能看懂「这次大概多少钱」。 |

### 不实用

| 证据 | 为什么 |
|---|---|
| 历史是对话标题（「在当前工作目录写 hello-b1.txt…」），不是「上次我签了什么」 | 委托方不读 Thought Process。 |
| 已完成底部是「追加指令 / 继续对话」，不是导出给财务 | 签字位和续聊位混在一起。 |
| B6「计划 + 多 agent、指挥中心停其中一条」没有跑成甘特。双角色录像里指挥中心点停止，原文「已请求停止：只做计划：…」，计划提问 run 被停掉 | 能停是好的；停的不是并行子任务，是还在问口径的计划。 |
| 等批准时产物坞先打开目标文件名并报「读取失败」，磁盘还没有这个文件 | 委托方会以为已经写了。批准键在 `b-code-card` 上看得见。 |

收口：批准人话、停止三分词、首页花费，这三件比档案好。看板在提问挂起时说什么，本轮没拍到，不写进结论。

## 安全敏感用户

### 好

| 证据 | 原文 |
|---|---|
| 出厂默认不是全放行 | 普查 `autoApprove=false`。运行设置：「自动放行 / 默认先问；勾上才自动放行」。权限档：「手动 · 危险动作会先问你，不会自动放行」。 |
| 拒绝之后文件真的不在 | `hello-b2-denied.txt` 磁盘 **False**。 |
| 批准文案能看出将要写哪个文件、写什么 | 「要新建或改 hello-code.txt，写入「code-ok」」。 |
| 启动横幅 / 截图纪律：本轮 shots 未写入 Key。设置模型页点过，报告不贴 Key | 密钥不能进评测正文。 |
| `[hidden]` 抽查：`reconnect-banner` / `budget-extend-row` / `submit-error` / `run-knobs` 均为 `display:none`，`lie=false` | 已终止界面没有用 flex 把「等待模型」撑出来（这几个 id）。 |

### 不习惯

| 证据 | 我本来以为会…… |
|---|---|
| `shots/a30-settings-mcp.png` 实际是模型 / 角色分配，不是 MCP 页。MCP「未连接」本轮没有合格画面 | 没拍到就不写「设置里已经人话未连接」。 |
| 飞书入站：欢迎卡「现在只能在这个窗口下指令。」——诚实。`npm run im:tunnel` 示例仍写 `cloudflared tunnel --url http://127.0.0.1:4173`，评测宿主却是 4174 | 文档端口跟活宿主走。 |

### 不实用

| 证据 | 为什么 |
|---|---|
| 今日花费把评测机以外的全局 ledger 算进来（`totalUsd≈2.75`，今日 runs=20） | 独立 history 目录没有隔开用量，审计口径漂。 |
| 桌面用户数据目录仍叫 `C:\Users\rk302\AppData\Roaming\Agent Harness`（Electron CommandLine） | 窗框写 FATHOM，磁盘配置名还是旧产品名。 |

收口：默认先问、拒绝不写盘、人话批准，安全岗第一眼不会立刻停用。用量串账和 MCP 人话是还没关上的口子。
