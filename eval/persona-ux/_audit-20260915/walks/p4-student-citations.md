# P4 · 学生 / 省钱用户 + 引用型调研员

- **日期：** 2026-09-15
- **表面：** 仅 Web。学生走用量/停止；调研员走 consult 入口与出处。未配公网检索长跑（避免再烧一轮）。
- **习惯伸手：** 学生：打开就打字，找还剩多少、停止。调研员：答案旁边有没有可点来源。

---

## 学生 / 省钱用户

### 好

| 证据 | 原文 |
|---|---|
| 打开就能打字 | 新手卡「打一句话，回车」。占位「说要做什么…」。 |
| 用量在首页 | 「今日 $1.98」「这次约 $0.0003 · 今日 $2.01」。点芯片进设置/消耗。 |
| 停止找得到，停完说人话 | B4 发送键位置变成停止；事后「已停止」，不是「运行已完成」。 |
| 失败没有把 HTTP 原文甩在 B12 的 Code/Work POST 上 | 两条 `POST /api/runs` 都是 **200**。 |

### 不习惯

| 证据 | 我本来以为会…… |
|---|---|
| 数字是美元和「今日已用 20 次」，没有「这个月免费额度还剩几次」 | 学生要的是次数/积分，不是 token 跑道——活页改成 $ 了，但仍是全局总账。 |
| 设置九页都在（外观/模型/MCP/领域包/运行默认值/通知/快捷键/消耗/关于）。冷启动不必填 Key | 设置太深会放弃——现在默认藏旋钮，点开仍很长。 |

### 不实用

| 证据 | 为什么 |
|---|---|
| 独立 `AGENT_RUN_HISTORY_DIR` 没有让「今日 $」归零。评测机一开就是快两美元 | 换一台「干净」宿主，学生会以为自己已经花了钱。 |
| 生图未配置写清楚了；识图写着 kimi-k3，本轮没测，不能当作业插图工具 | 没配的能力不要出现在欢迎卡。欢迎卡没推识图，这点诚实。 |

收口：冷启动和停止够用。用量数字会吓到「我还没开始就 $2」。

## 引用型调研员

### 好

| 证据 | 原文 |
|---|---|
| 运行设置里有 `consult · 查资料` | `B10-consult-option` 下拉含这一项。 knobs 提示「查资料选 consult」。 |
| Work 空态有「带出处问答 / 回答时列出来说 / 该页说的 / 链接」 | 伸手方向对。 |
| 「引用会话」是单独按钮，欢迎卡声明它不是文献 | 「旧对话用「引用会话」。」 |

### 不习惯

| 证据 | 我本来以为会…… |
|---|---|
| consult 仍是领域包下拉里的一项，默认「不用领域包」 | 问资料时默认带来源表，不必先懂「包」。 |
| `#` 空响，不能拿会话当文献，也不能当过滤 | 出处区应是链接，不是符号。 |

### 不实用

| 证据 | 为什么 |
|---|---|
| 本轮没有发出 consult 真对话，因此**没有**可点来源表的屏幕原文。不能把下拉选项写成「已经有出处栏」 | 无出处 = 还没测到工具形态。 |
| 「引用会话」面板普查时是空的（当时尚无运行） | 容易和「引用文献」搞混的名字还在，只是欢迎卡打了补丁。 |

收口：入口比档案好（有 consult、有带出处 starter）。作为调研工具仍未在本轮活页上交出可点链接。
